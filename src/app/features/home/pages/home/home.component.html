SET Game

Find sets of cards as fast as you can!

How to Play

A SET consists of 3 cards where each feature is either: all the same or all different.

Color

All same or all different

Shape

All same or all different

Number

All same or all different

Shading

All same or all different

What is a valid set?

For each feature (color, shape, number, shading), the cards must be:

  • All the same
  • OR all different

If even one feature breaks this rule → it is NOT a set.
